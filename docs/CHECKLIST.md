# Poster Checklist

Tick these off before you call the poster finished.

## Must appear (if you supplied them)

- [ ] Clear headline (stall, product or event name)
- [ ] Exact date(s)
- [ ] Times
- [ ] Specific location (market name + area or address)
- [ ] Contact method (phone, email or how to DM)
- [ ] Social media and/or website
- [ ] Prices or a clear pricing statement
- [ ] Short description of what you are offering
- [ ] Simple call to action

## Easy-to-read checks

- [ ] Headline, date and location are the largest text
- [ ] High contrast — text is easy to read
- [ ] Nothing important is cut off or too close to the edge
- [ ] Spelling and numbers are correct
- [ ] Not overcrowded

If any essential detail you gave is missing, do one edit round.
