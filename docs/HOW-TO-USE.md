# How to Use These Prompts

## 1. Gather your details

Use the short list in `templates/input-template.md`. Fill in only what applies to you. Leave blank anything you do not have.

## 2. Pick a tool

| Tool | Good for | Notes |
|------|----------|-------|
| Ideogram | Accurate text on the poster | Strong free option for readable dates, prices and contact details |
| ChatGPT | High quality + easy edits | Limited free images |
| Canva | Templates + final layout & print | Free editor is excellent for finishing |
| Microsoft Designer | Quick editable posters | Free with a Microsoft account |
| Leonardo.AI | Trying several styles | Daily free tokens |
| Others | Experiments | Check the free-tier note in each folder |

## 3. Generate

- Open the tool
- Paste the prompt from that tool’s folder
- Replace the placeholders with your real details
- Say the format you want (A3 print or a social media size)
- Generate

## 4. Check and edit

Use the checklist in `docs/CHECKLIST.md`. If something important is missing or wrong, do one targeted edit. Most free plans only allow a small number of generations, so plan for one or two rounds maximum.

## 5. Finish for print or social

- **Social media**: Most generators can make square or tall images directly.
- **A3 print** (297 × 420 mm): Generators rarely output true print resolution. Take the best visual, open free Canva or Microsoft Designer, set the page to A3, place perfect text, and export a PDF for your printer.

That is all you need for a practical poster.
