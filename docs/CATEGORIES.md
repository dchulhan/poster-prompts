# Theme Categories

Set the Category field in any prompt to change the visual character.

- **Food & Drink** — warm, appetising, generous
- **Craft & Handmade** — textural, personal, careful
- **Fashion & Accessories** — clean, stylish, wearable
- **Plants & Garden** — fresh, organic, calm
- **Holiday / Seasonal** — festive or seasonal mood, still readable
- **Community Event** — welcoming, open, local
- **Services** — clear, trustworthy, direct
- **General Market** — bold, straightforward, energetic

The category changes imagery and mood. It does not remove the need for dates, location, prices, contact, etc.
